Currency Converter - Конвертер валют

Выполнил - Колесников Александр Александрович

Currency Converter — это графическое приложение для конвертации валют с использованием актуальных курсов из внешнего API. Программа позволяет:

- Конвертировать сумму из одной валюты в другую
- Получать актуальные курсы валют в реальном времени
- Просматривать историю всех конвертаций
- Экспортировать историю в JSON файл
- Автоматически сохранять историю между запусками
Поддерживаемые валюты: USD, EUR, RUB, GBP, CNY, JPY, CHF, CAD, AUD, TRY, KZT, UAH, BYN, PLN, INR, BRL, MXN, KRW, AED, SAR и другие.

Как получить API-ключ:
1. Перейдите на сайт [ExchangeRate-API](https://app.exchangerate-api.com/sign-up)
2. Зарегистрируйтесь (бесплатный план позволяет до 1500 запросов в месяц)
3. После регистрации вы получите API-ключ
4. В файле `currency_converter.py` найдите строку:
   ```python
   self.api_key = "ВАШ_API_КЛЮЧ"
Замените "ВАШ_API_КЛЮЧ" на ваш реальный ключ

Инструкция по запуску:

Требования:
- Python 3.6 или выше
- Установленная библиотека requests

Зависимости:
pip install -r requirements.txt

Или просто: pip install requests

Для запуска ввести команду: 
python currency_converter.py
